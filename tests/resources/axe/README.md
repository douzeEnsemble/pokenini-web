# axe-core

`axe.min.js` is [axe-core](https://github.com/dequelabs/axe-core) 4.14.1 (MPL-2.0, see `LICENSE`), copied unchanged from the npm package. The accessibility browser tests inject it into the page (`tests/src/Browser/Accessibility/AccessibilityTest.php`).

To update it: `npm pack axe-core@<version>`, extract `package/axe.min.js` and `package/LICENSE` here, and change the version above.
